This project adds MIDI support to the Gakken SX-150 mk II using an Arduino R4.

This includes CCs for all original controls, plus additional parameters.

## Additional Hardware Features:
- Sustain and Release Stages (for existing hardware envelope)
- Inverted Envelope Mode
- Pulse, Dual Pulse, Super Saw, and other Waveforms
- Pulse Width Modulation
- Square and Triangle Sub Oscillators
- VCF Drive adjustment
- Envelope to VCF Depth Adjustment
- High Pass Filter Mode
- LFO to VCF Modulation
- Improved LFO sync
- VCA
- LED indicators for LFO and Envelope

## Additional Software Features:
 - Extra Software Envelopes with S/H
 - Extra Software LFOs
 - Pitch Bend
 - Portamento
 - Legato
 - Velocity-triggered Accent
 - Velocity Modulation
 - VCF Keytracking
 - Delay and Fade-in for Hardware LFO
 - Quantizing for Touchstrip
